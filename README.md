I'm Nicksen, a Full-Stack Web Developer focused on building fast, reliable, and user-friendly web applications. I work extensively with React and Vite on the frontend, paired with Cloudflare Pages and Workers KV for lightweight, serverless backends. From company profile websites to full-featured PWAs, my specialization lies in shipping production-ready apps — with a strong attention to performance, real-world usability, and clean architecture. I build and deploy from anywhere, mobile included, and I'm always looking to sharpen my craft one project at a time.
